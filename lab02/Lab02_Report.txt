3. Analysis (The GIL):
Multithreading ไม่สามารถทำให้โปรแกรมทำงานเร็วขึ้นได้เพราะติดข้อจำกัด GIL (Global Interpreter Lock) ของ 
Python ที่บังคับให้ประมวลผลได้ทีละ 1 Thread เท่านั้น ในขณะที่ Multiprocessing เป็นการโคลน Process ใหม่แยกออกจากกันอย่างเด็ดขาด แต่ละ Process 
มีหน่วยความจำและ GIL เป็นของตัวเอง OS จึงสามารถกระจายงาน CPU-bound ไปให้คอร์อื่นๆ ทำงานคู่ขนานกันได้
และเพื่อป้องกันปัญหา Zombie Process เมื่อใช้งาน Process ตัว Parent จะต้องเรียกใช้คำสั่ง os.wait() เสมอ
